SOFT BLACK ARROW CURSOR v2 — COMPLETE WINDOWS SCHEME

This version fixes the shadow by rebuilding it as genuine alpha transparency.
There is no white or blue rectangular background in the cursor files.

Included Windows roles (17 total):
Normal, Help, Working in Background, Busy, Precision, Text, Handwriting,
Unavailable, Vertical Resize, Horizontal Resize, both Diagonal Resizes, Move,
Alternate Select, Link, Location, and Person.

Working in Background and Busy are animated. Every cursor contains multiple
sizes (32, 48, 64, 96, and 128 pixels where applicable) and a role-specific
click hotspot.

INSTALL
Right-click Install.ps1 and choose "Run with PowerShell".

RESTORE
Right-click Restore.ps1 and choose "Run with PowerShell".

Windows installs the active files under:
%LOCALAPPDATA%\CustomCursors\SoftBlackArrowV2
