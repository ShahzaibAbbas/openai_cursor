Install

Current user only. No administrator rights and no system files are touched.

Download and extract

Get the ZIP above and extract it anywhere. The installer copies everything it needs into a permanent folder.

Double-click Install.cmd

It applies the scheme, keeps your pointer size and colour, and starts the small tray helper that keeps the scheme in place after sign-in.

Install.cmd Classic

Pick a style any time

Right-click the tray icon, then Animation: Lively, Classic or Static. Or run it from a terminal:

CursorKeeper.exe --style Static
StyleAnimated pointersUse it when
Lively defaultNormal, Busy, Working, Help, Link, Location, Person, UnavailableYou like a pointer that feels alive. Every loop shares one 3.2 s rhythm.
ClassicNormal, Busy, WorkingYou want the original v3 behaviour.
StaticNoneYou prefer no motion. This style is also used automatically while Windows "Animation effects" is off.

To undo: Stop-Protection.cmd stops the helper and keeps the scheme. Restore.cmd puts back your exact previous pointers.
